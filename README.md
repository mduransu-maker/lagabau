# LAGA Bau – Website Demo

Moderne responsive Demo-Website für **LAGA Bau & Gebäudeservice**.

## Enthalten
- Responsive One-Page-Website
- Leistungen: Bauschutt, Grünschnitt, Holz, Erde, Heckenschnitt, Rasenpflege, Baumfällung
- Mobile Navigation und Scroll-Animationen
- Kontakt-Demoformular
- GitHub-Pages-Workflow

> Hinweis: Das Kontaktformular ist in dieser Demo rein clientseitig und versendet keine Daten.
